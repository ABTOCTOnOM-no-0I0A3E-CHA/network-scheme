# Руководство администратора network-scheme

Self-hosted NMS для сетей на 500–5 000 устройств с поддержкой Eltex MES/ESR: мониторинг, топология,
syslog и трапы, бэкапы конфигураций и изменение конфигураций через изолированный executor.

## Общие правила

- Все команды `nmsctl` выполняются **на хосте от root** (`sudo`). Операции «только с хоста» —
  TOTP изменений, гранты и политика executor'а, снятие freeze, разблокировки, сброс пароля и TOTP
  пользователей панели, ротация ключей — существуют только в `nmsctl`, через веб их сделать нельзя.
- Полный список команд: `nmsctl` без аргументов, `nmsctl executor` без аргументов.
- Приложение не делает исходящих соединений: нет телеметрии, CDN и проверки обновлений.
  Обновления — только подписанные бандлы, которые администратор приносит сам.
- Пути установки: конфигурация и секреты — `/etc/nms` (секреты — `/etc/nms/secrets`), данные хоста —
  `/var/lib/nms`, бинарник — `/usr/local/bin/nmsctl`, compose-проект — `/etc/nms/compose.yaml`
  (имя проекта `nms`).
- Права в панели (роли, группы, пользователи) настраиваются в самой панели; права на **изменение**
  устройств выдаются только в executor'е через `nmsctl executor grant`.
- В примерах используются адреса `192.0.2.0/24` и домен `example.org` — замените своими.
